=====REGISTRY=====
Turtle searches all the loaded plugins for any plugins that implement the CBS then calls the class#registerBlocks method.
This is done to allow for the plugin to register blocks that are not in the vanilla game.
The plugin owns the blocks so if it is removed or unloaded then the blocks will be replaced with a substitute vanilla block.
The data will still live inside the chunks PDC at that location until overriden by a world event such as an explosion.
All namespaces/blocks will live inside the world PDC as a list that can be compared against what is registered. If theres a difference then disable the plugin and go into safety mode.
