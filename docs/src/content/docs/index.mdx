BlockEngine is a Paper plugin for building custom blocks that behave like first-class server objects while staying compatible with Minecraft clients through generated resource packs.

It gives plugin authors and pack authors the same core path:

- register a block id such as `example:ruby_block`
- define how the item looks and places
- generate the resource-pack models and translations
- persist placed custom blocks in loaded worlds
- expose blocks through catalog and creative-menu flows

## Pick an integration path
