## Main entry points

- `CustomBlockSystem` is implemented by your plugin or integration class. It registers adapters, declares the namespace, sets pack details, and exposes version metadata.
- `BlockAdapter` defines one custom block and owns its runtime behavior.
- `BlockDefinition.Builder` describes the static block contract: fallback material, item model, catalog visibility, creative-menu visibility, placement behavior, and state definitions.
- `BlockData` stores public placed-block data such as strings, numbers, booleans, locations, item stacks, and inventories.
- `PackDetails` declares generated resource-pack metadata and any additional asset roots your integration contributes.

## Local generation

Run Javadocs from the repository root:

```bash
./gradlew :blockengine-api:javadoc
```

The generated output is published under the docs site's `/api/` path during the GitHub Pages release workflow.

## Troubleshooting

If the generated Javadocs link returns `404` immediately after a release, wait for the Pages workflow to finish and refresh the site. The Starlight page you are reading is built with the docs, while the generated Javadocs are copied into the final Pages artifact as a separate API directory.
